# Космический Штурм: Ультра

Готовый к публикации браузерный космический roguelite-шутер. Игра работает без сервера, поддерживает клавиатуру, мышь и сенсорное управление, автоматически масштабируется под iframe и мобильный экран.

## Запуск

```bash
npm ci
npm run dev
```

Проверка релизной версии:

```bash
npm run build
npm run preview -- --host 0.0.0.0
```

## Публикация в Яндекс Играх

1. Создайте игру в [консоли разработчика Яндекс Игр](https://games.yandex.ru/console/).
2. Подключите монетизацию (реклама и/или инапы) — без неё игру не пропустят (требование §1.12, см. [«Монетизация»](https://yandex.ru/dev/games/doc/ru/console/adv-monetization)).
3. В черновике включите опцию **«Игра использует облачные сохранения»** — игра пишет прогресс и рекорд в данные игрока (обязательное требование §1.11).
4. В разделе **Лидерборды** создайте лидерборд с техническим именем `highscore` (тип — числовой, сортировка по убыванию). Если лидерборд не нужен, игру можно опубликовать и без него: интеграция корректно пропустит отправку результата.
5. В разделе **Инапы** создайте постоянную покупку с ID `void_wraith` — она навсегда открывает пятый корабль «Призрак Немезида». Цену задайте в консоли Яндекса. Покупку нельзя делать расходуемой. Опционально можно добавить продукты `premium_pass` и `starter_pack`: если их нет в консоли или они неактивны, игра автоматически скроет их из магазина (требование §1.13.6 — паритет с каталогом).
6. Соберите архив:

   ```bash
   npm run package:yandex
   ```

7. Загрузите файл `space-shooter-yandex.zip` в черновик игры. В корне архива уже находится `index.html`, SDK подключён относительным путём `/sdk.js`.
8. Укажите ориентацию **альбомная**, минимальный размер экрана — **360×240**. В списке поддерживаемых языков оставьте **только русский**: текущая версия получает язык через `ysdk.environment.i18n.lang`, а весь игровой контент локализован на русский. Не добавляйте английский или другие языки до появления полного перевода.
9. Перед отправкой на модерацию откройте черновик с debug-панелью (`?debug-mode=16`) и убедитесь, что индикатор лоадера показывает `IT` (SDK инициализирован верно; `IF` — старый лоадер, модерация это не пропустит).
10. Добавьте в карточку иконку, обложку, скриншоты и описание, заполните возрастной рейтинг, затем отправьте черновик на модерацию.

## Что интегрировано с Yandex Games SDK

- SDK подключается относительным путём `/sdk.js` (актуальный способ для хостинга Яндекса);
- `LoadingAPI.ready()` после готовности интерфейса;
- `GameplayAPI.start()` / `stop()` при игре, паузе, выборе улучшений и рекламе;
- события платформы `game_api_pause` / `game_api_resume` (автоматическая стартовая реклама, окно покупки, переключение вкладок): звук и геймплей ставятся на паузу;
- смена игрового аккаунта через диалог платформы (`ACCOUNT_SELECTION_DIALOG_*`): запись в облако приостанавливается, объект игрока перечитывается, состояние игры перезагружается под выбранный аккаунт;
- rewarded-реклама: один экстренный ремонт на попытку (+50% HP и временная неуязвимость), рероллы улучшений и бонусный выбор;
- полноэкранная реклама в естественной точке — при выходе в меню после завершения забега, с ограничением частоты 3 минуты (плюс платформа управляет частотой сама);
- облачное хранение рекорда и мета-прогресса через данные игрока с соблюдением лимитов (не чаще 100 запросов/5 мин, ≤200 КБ на игрока; слияние записей в один запрос, немедленная отправка результатов забега);
- отправка рекорда в лидерборд `highscore` через актуальный `ysdk.leaderboards.setScore()` с проверкой `isAvailableMethod` (гости пропускаются) и лимитом 1 запрос/с; старый `getLeaderboards()` оставлен как fallback;
- постоянные инап-покупки `void_wraith`, `premium_pass`, `starter_pack`: восстановление через один `getPurchases()` на каждый запуск (с ретраем при сетевом сбое), цены и валюта — одним `getCatalog()`;
- безопасный fallback: локально и при недоступном SDK игра полностью работает без рекламы и облака.

## Управление

- **WASD / стрелки / зажатая левая кнопка / свайп** — движение;
- **Shift / правая кнопка мыши** — рывок;
- **X** — ядерный заряд;
- **C** — замедление времени;
- **M** — звук;
- **Esc** — пауза.

Оружие стреляет автоматически. Во время выбора улучшения бой полностью останавливается.

## Саундтрек

Вся музыка генерируется процедурно (WebAudio, без файлов): «Звёздная гавань» в меню и ангаре, «Погоня в пустоте» во время волн, «Пробуждение титана» в боях с боссами, отдельные джинглы победы и поражения. Громкость музыки и эффектов настраивается раздельно.
