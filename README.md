# Space Shooter Ultra

Готовый к публикации браузерный космический roguelite-шутер. Игра работает без сервера, поддерживает клавиатуру, мышь и сенсорное управление, автоматически масштабируется под iframe и мобильный экран.

## Запуск

```bash
npm ci
npm run dev
```

Проверка релизной версии:

```bash
npm run build
npm run preview -- --host 0.0.0.0
```

## Публикация в Яндекс Играх

1. Создайте игру в [консоли разработчика Яндекс Игр](https://games.yandex.ru/console/).
2. В разделе **Лидерборды** создайте лидерборд с техническим именем `highscore` (тип — числовой, сортировка по убыванию). Если лидерборд не нужен, игру можно опубликовать и без него: интеграция корректно пропустит отправку результата.
3. Соберите архив:

   ```bash
   npm run package:yandex
   ```

4. Загрузите файл `space-shooter-yandex.zip` в черновик игры. В корне архива уже находится `index.html`.
5. Укажите ориентацию **альбомная**, минимальный размер экрана — **360×240**, язык — **русский**.
6. Добавьте в карточку иконку, обложку, скриншоты и описание, заполните возрастной рейтинг, затем отправьте черновик на модерацию.

## Что интегрировано с Yandex Games SDK

- `LoadingAPI.ready()` после готовности интерфейса;
- `GameplayAPI.start()` / `stop()` при игре, паузе, выборе улучшений и рекламе;
- rewarded-реклама: один экстренный ремонт на попытку (+50% HP и временная неуязвимость);
- полноэкранная реклама в естественной точке — при выходе в меню после завершения забега, с ограничением частоты 3 минуты;
- облачное хранение рекорда через данные игрока;
- отправка рекорда в лидерборд `highscore`;
- безопасный fallback: локально и при недоступном SDK игра полностью работает без рекламы и облака.

## Управление

- **WASD / стрелки / зажатая левая кнопка / свайп** — движение;
- **Shift / правая кнопка мыши** — рывок;
- **X** — ядерный заряд;
- **C** — замедление времени;
- **M** — звук;
- **Esc** — пауза.

Оружие стреляет автоматически. Во время выбора улучшения бой полностью останавливается.
